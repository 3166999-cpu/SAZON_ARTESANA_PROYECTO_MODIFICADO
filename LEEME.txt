SAZÓN ARTESANA - PROYECTO MODIFICADO

Este proyecto conserva el estilo visual original y deja únicamente estas secciones en la página principal:
- Inicio
- Producto
- Quiénes somos
- Ingresar datos
- Venta

ARCHIVOS:
- index.html: página principal con productos, formulario de cliente y carrito/venta.
- css/style.css: estilos originales de SAZÓN ARTESANA.
- js/main.js: navegación suave y año automático.

CÓMO ABRIR:
1. Extrae la carpeta ZIP.
2. No cambies los nombres ni la ubicación de los archivos.
3. Abre index.html en tu navegador.

NOTA SOBRE LAS VENTAS:
La venta se calcula y muestra en el navegador, y se puede imprimir. Este proyecto no guarda datos en una base de datos ni procesa pagos reales. Los datos no se conservan al cerrar o recargar la página.

Las imágenes y recursos de Bootstrap/Google Fonts se cargan desde internet.
